## Endpoints (`/api/nineweave`)

`GET /health`, `GET /heroes`, `POST /auth/device`, `GET|PATCH /me`,
`GET /leaderboard`, `GET /rooms` (alias `/lobby`), `POST /rooms`,
`GET /rooms/<CODE>?since=n`, `POST /rooms/<CODE>/join`, `/moves`,
`/rematch`, `/leave`, `/cancel`, plus `OPTIONS` on everything. Full contract:
`ONLINE_API.md`.

## Schema summary

- **`nw_players`**: public `id`, `token_hash` (unique), `screen_name` (unique
  on `lower()`), `apple_sub` (nullable, unique, reserved), `purchases` and
  `unlocks` (jsonb, default `[]`), `last_hero_id`, `matches_won`,
  `matches_lost`, `matches_played`, `boards_won`, and timestamps. Partial
  leaderboard index on `(matches_won desc, …)` for named players who have
  played.
- **`nw_rooms`**: `code` (unique among non-closed rooms), `status`
  (waiting/active/finished/closed), `is_private` + scrypt `password_hash`,
  `round`, `x_slot`, `state` (the `rules.gd` snapshot as jsonb), `rev` (the
  optimistic version), host and guest slot columns (player id, name, hero,
  seat-token hash, seen-at, rematch flag), `left_slot`, `winner_slot`,
  `end_reason`, `turn_started_at`. Indexes cover code, lobby, status/activity
  and active-turn lookups.
- **`nw_matches`**: append-only result log, unique on `(room_id, round)`:
  X/O players, names, heroes, result, end reason, boards per side, move count.

## Design decisions to review

- **Atomicity over Neon HTTP:** the driver's transactions are
  non-interactive, so each write is one batch: `update … where rev = <read>`,
  then a `1/count(*)` guard on the new `rev` that aborts the batch if a
  concurrent writer won. The caller then re-reads and retries (up to 5 times,
  then returns 503). Match-end record updates are in that same batch.
- **Turn timeout:** the player **due to move** forfeits after 180 s without a
  move, even if they are still polling. A timeout is treated exactly like
  leaving: the room closes and the opponent sees `opponent_left`.
- **Draws** increment `matches_played` only. **Forfeits** count as a loss
  for the leaver and a win for the opponent. `boards_won` counts claimed
  boards on every match end, forfeits included.
- **Rematch during a live game** returns `200` with `ignored: true`.
- **Production without a database URL** returns 503 for the API instead of
  using PGLite. That fallback crashed the built server at startup, homepage
  included, because the bundle lacks PGLite's data file.

## Not done / out of scope

- Schema `0002_nineweave_online.sql` is applied on the Nineweave Neon
  database (`npm run db:migrate`, 12 statements). Re-running migrate is a no-op
  once `_migrations` already lists that file.
- The Neon HTTP path was used to apply the schema. Gameplay was tested on
  PGLite, not against a live match on Neon. A smoke game against Neon after
  go-live is still a good idea.
- No Godot client changes. The optional additions (device token on
  create/join, a `/leave` call) are listed at the end of `ONLINE_API.md`.
- No Sign in with Apple and no IAP/receipt validation. Only the `apple_sub`
  column is reserved.
- No reconnect UX beyond reusing the seat token, and no moderation tools.

## Risks

- **`NINEWEAVE_DATABASE_URL` is set on this box.** Plain `npm run build`,
  `npm run db:migrate` or `npm run dev` here **will use the real Nineweave
  Neon database**: build migrates it and dev reads and writes it. Use
  `env -u NINEWEAVE_DATABASE_URL -u DATABASE_URL …` for local-only work.
- Anonymous device tokens make farming wins with several devices trivial,
  and wins against anonymous opponents still count. That's acceptable for a
  casual leaderboard, but not for anything with stakes.
- `purchases` and `unlocks` are client-writable and unverified until Apple
  receipt validation exists.
- Rate limits live in memory per instance, so they're best-effort only.
- The Godot client maps 404 (an expired or unknown room code) to its generic
  "Online server not available yet" message. That's a client UX issue, and
  the protocol requires 404.
- `npm test` exits non-zero because of the 15 pre-existing template failures
  described above.
